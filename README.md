# Rondo

A routine runner for the iPhone home screen: one step at a time, with a shrinking timer disc.
It runs entirely on the device as an offline Progressive Web App, with no backend, accounts or
analytics.

Live at https://float.lefant.net/rondo/. To install, open it in Safari, then
Share → Add to Home Screen.

```
npm install
npm run dev      # Vite dev server
npm test         # Vitest
npm run lint     # ESLint
npm run deploy   # build and publish to GitHub Pages
```

Design choices are recorded in [docs/decisions.md](docs/decisions.md).
